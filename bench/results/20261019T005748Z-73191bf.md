## Axiom native: check once, run many

Run = one call of the generated `beryl_kernel`, same protocol as the C/Rust kernels. Compile = Axiom admission, checked selection and C emission, plus the C compiler. Generated kernels are shape-specialized with 32-bit outputs; the C/Rust baselines take sizes at runtime and store 64-bit outputs. "Hand C" removes that difference: hand-written C with the same ABI, compile-time shape, int32 types, harness and flags.
