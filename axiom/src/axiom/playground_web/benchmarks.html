Compiled programs: beryl, C and Rust

All three programs are compiled before timing. Each measured process starts, reads the same inputs, computes the stencil and writes its output. Every output is verified after timing.

beryl lowers its checked plan to C and uses Clang to build the executable. C and Rust use direct implementations. Small cases are dominated by process startup and input/output. These measurements compare these programs on one machine; C and Rust do not run on this page.
