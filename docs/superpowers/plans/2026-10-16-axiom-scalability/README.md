# Project Axiom: scalable checked execution

Planning package dated 2026-10-16. Status: draft under independent review; implementation has not started.

The milestone is a fixed-shape declarative stencil executing through a compact, independently checked plan and the production Core backend, with complete native results checked against an independent source oracle. Qualified performance research follows correctness. Core remains the separate 4GL language; Axiom remains the confidential 5GL research project.

This package will contain the common design, dependency and acceptance gates, subsystem implementation plans, and research/publication plan. The user's authorization permits separately reviewed Core changes if a demonstrated buffer/export gap requires them.
