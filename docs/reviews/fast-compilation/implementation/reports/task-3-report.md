## Interface and frozen contract

- `_select_ranked(context, total_check_steps) -> (FastSearchResult, _OwnedCheck | None)`; accepts an exact live `_CompilationContext`, uses its immutable source/kernel/limits and owned candidate/check/authorization API.
- `POLICY_ID = 'ranked-proof-v1'`, `REPORT_VERSION = 2`. Legacy `select_plan`, ranking tuple version and accounting version are unchanged.
- `ranked_policy_digest(objective)` binds policy/report version, objective ranking digest, fixed portfolio order, stable identical-key tie rule, structural metrics, full-generation-before-proof rule, all-unknown abort rule, shared/per-call budget and no-receipt exception charging. Pinned digests: multiplication_ops `45bbc9ceff403c30f4d1b4fb50e9fd326bed1c1b5cc1cac4f1ca8aae57b94f64`; plan_workspace_bytes `f2de163e2f82b4c54d22186fc90d104f3c570ccc52e7977a5062f844644504f7`.
- Frozen `FastAttemptRecord` includes candidate_id, typed state, complete structural multiplication_ops/workspace_bytes/operation_count/ranking_key (or None when validation did not complete), optional plan_digest/check, allowance/work_used, source/semantic/constraint/ranking/policy digests and reason.
- Attempts remain in portfolio order. `not_checked` makes no semantic claim for fully validated candidates on an aborted search; only successful selection changes remaining feasible candidates to `not_checked_worse_rank`. Other states: `structurally_rejected`, `constraint_rejected`, `proved_invalid`, `proved_eligible`, `unknown`. Skipped attempts never fabricate semantic receipts or canonical digests.
- `FastSearchResult` contains attempts, termination_reason/reason, selected_plan/selected_plan_bytes/selected_check/selected_key, objective, accounting version, total budget/used work, artifact_state, limits, report_version/policy_id/policy_digest and portfolio_optimal.
- Stop reasons: completed, no_eligible_candidate, total_budget_exhausted, check_limit_exhausted, unknown, checker_error, candidate_error, cancelled. `portfolio_optimal` is true only with a returned owned eligible winner; it is false for all no-artifact outcomes, including conclusively empty portfolios.
- Generation/validation completes before proofs, even with zero semantic budget. Only `INVALID_PLAN` during validation is conclusively structurally rejected. Unsupported opcodes/versions, resource limits and other inconclusive decode errors stop with unknown; generation/checker errors and KeyboardInterrupt stop without an artifact.
- Each check receives min(total remaining, per-check limit). A valid work receipt charges its exact work; exception/malformed work receipt consumes the entire reserved allowance. Lazy encoding happens before checker reservation, so encoding failure/cancellation consumes zero semantic work. Later checks never reset the shared budget.
- A candidate's real full-stream metrics come from context validation, with operation_count from the validated immutable tuple length. Ranking uses only the existing `(primary, secondary, actual_plan_id)` tuple, stably. Eligible proof must match source/plan/checker/constraint identities and complete multiplication/workspace/operation counts before authorization.

## Self-review

Ordering: the entire portfolio is generated and examined; structural invalidity and cap rejection are conclusive. Surviving candidates are sorted by the exact existing tuple, retaining original order on complete ties. Before the first eligible candidate, every proved candidate is conclusively invalid. Every unproved survivor has a greater or equal key, so cannot improve that winner; stable ties retain the legacy winner. Eligible proof metrics and identities must agree before an owned artifact is issued. This establishes only the fixed portfolio optimum.

Terminal states: every unknown, exception or cancellation returns no selected plan/bytes/check and no owned artifact, with portfolio_optimal false. Later validated candidates retain not_checked on abort. Conclusive empty portfolios return no_eligible_candidate without an optimality claim. Budget accounting always equals summed attempt charges and cannot exceed the shared budget. Source/plan/expression quotas remain independent of semantic allowance. No public receipt or digest becomes authority; context authorization must register the successful check.

Limitations: service/JSON/UI integration belongs to Task 7. Legacy interpreter report schema remains untouched. Full production suite runs at coordinator integration, per assignment; no benchmark or wall-time improvement claim was made. KeyboardInterrupt cancellation is best effort, not a deterministic work-limit promise. The private owned protocol is not a defense against arbitrary hostile Python in the same process.
