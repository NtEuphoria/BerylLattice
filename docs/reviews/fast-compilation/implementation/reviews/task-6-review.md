## Evidence and reasoning

- Emission first requires the live identity-issued `_OwnedCheck`, then freshly decodes and validates the exact hint and compares its entire expansion to the owned finite stream. It uses that call's validated program directly. A caller-supplied correspondence record or matching hash cannot authorize emission (`bounded_loop_wasm.py:115-132`; `compilation.py:141-160`; `bounded_loop_correspondence.py:161-179`). The owned complete finite check retains arithmetic safety for every primitive, including dead operations, and rejects uninitialized scratch loads.
- `_loop` has a dedicated enclosing break block and loop label. Its condition executes with break depth 1 and its trailing continue has depth 0; nested child labels are closed before either trailing instruction. Signed `ge_s` matches validated bounds `0 <= start <= stop <= 256`, so increments are safe and zero-trip loops execute no body. The preflight loop likewise stops at the admitted input count, at most 256 (`bounded_loop_wasm.py:22-28`; `bounded_loop_codec.py:72-80`).
- Local allocation respects validated lexical lifetime. Parent definitions and live induction variables remain allocated during child emission; child definitions are released only at child block exit, and the induction local only after that loop. Siblings may reuse freed slots, while every emitted scalar use has an earlier definition in its active scope. The preflight local is released after the scan and can safely be overwritten by body definitions (`bounded_loop_wasm.py:45-110`).
- Index lowering preserves constant, variable-plus-offset, parity, coefficient multiplication, and accumulator addition order. `i32.and 1` implements mathematical nonnegative parity for signed negative components. Fresh correspondence checks every executed intermediate, final nonnegative index, and specialized arena bound. The validated loop increments and shared layout additionally make byte scaling/addition exact and keep input, output, and scratch disjoint within the fixed page (`bounded_loop_wasm.py:31-42`; `bounded_loop_correspondence.py:41-68,129-135`; `wasm.py:141-151`). Unexecuted zero-trip bodies do not require dynamically evaluated index bounds.
- The row-major preflight executes before the kernel body and contains no memory store. It returns the first invalid index plus one; thus invalid input preserves input, initialized output, scratch, and unused memory. Valid execution retains the complete finite stream's scratch reads/writes in order. Scratch need not be cleared: complete finite checking proves initialization within each invocation, and correspondence preserves it (`bounded_loop_wasm.py:64-74`; `checker.py:312-335`).
- The shared wrapper still exports only `memory` and `run`, with `run: () -> i32`, no imports, and one memory page with minimum and maximum both one. Public finite compilation continues to bind original source/plan bytes; the internal compact path binds owned source and canonical finite bytes plus exact raw hint digest, correspondence version, codegen version, and module digest. The fixed backend version/module identify the fixed ABI; no selectable codegen options were introduced. Label/origin metadata never substitutes for executable equality (`wasm.py:118-164`; `bounded_loop_wasm.py:125-132`).
- Extracting `_layout` and `_module` leaves finite instruction construction unchanged. The retained report additionally records byte equality for 18 finite modules against the earlier backend. The existing public fresh-check entry point and straight-stream fallback remain present; fallback selection itself belongs to integration.
